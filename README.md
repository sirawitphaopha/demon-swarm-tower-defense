# ⚔️ Demon Swarm TD

เกมแนว **Tower Defense (วางป้อมป้องกัน)** แบบ **3D** เล่นบนเบราว์เซอร์ (คอมพิวเตอร์) ธีมทุ่งหญ้าสดใส
วางป้อมขวางทางแมลงปีศาจ อย่าให้หลุดออกทางขวาเกิน 20 ตัว

เขียนด้วย **TypeScript + Three.js + Vite** — โมเดล 3D ทุกชิ้นปั้นด้วยโค้ด ไม่มีไฟล์โมเดล/เสียงภายนอก

---

## 🎮 วิธีเล่น

1. กด **เริ่มเกม** → จะมีช่วง **เตรียมตัว** ให้วางป้อมก่อนศัตรูบุก (มีครั้งเดียว หลังจากนั้นเวฟมาต่อกันไม่มีพัก)
2. เลือกป้อมจากแผงซ้าย แล้วคลิกบนสนามเพื่อวาง
3. วางป้อมต่อกันเป็น **เขาวงกต** เพื่อบังคับให้ศัตรูเดินอ้อม (ยิ่งทางยาว ยิ่งยิงได้นาน)
4. ฆ่าศัตรูได้เงิน เอาไปวางป้อมเพิ่มหรืออัปเกรด
5. คลิกป้อมที่วางแล้วเพื่อ **อัปเกรด / ขาย / เปลี่ยนเป้าเล็ง**
6. อย่าให้ศัตรูหลุดออกขวาเกิน 20 ตัว มิฉะนั้นแพ้

## ✨ ฟีเจอร์

- **ฉาก 3D การ์ตูน low-poly** แสงเงานุ่ม เส้นขอบการ์ตูน แสงเรือง (bloom) น้ำเคลื่อนไหว ต้นไม้ไหวตามลม
- **6 ป้อม** อัปเกรดต่อเชน: หินขว้าง → หอธนู → ครอสโบว์ → ปืนใหญ่(AOE) → ปืนกล → เลเซอร์ (หัวป้อมหมุนเล็ง เด้งถอยตอนยิง)
- **รีโหลด** ป้อมยิงได้เป็นชุด ยิงหมดชุดต้องหยุดเติมกระสุน มี **วงสีส้มรอบฐานป้อม** ค่อย ๆ เต็มจนครบวง และแผงข้อมูลบอกกระสุนที่เหลือ
- **เวฟต่อเนื่อง** ไม่มีช่วงพักระหว่างเวฟ ยิ่งเวฟหลังแมลงยิ่งมาถี่ เลือดหนา บอสมาบ่อยขึ้น
- **6 ศัตรู** หนอน / ด้วง / มอดเกราะ / แตนปีศาจ(บินข้ามป้อม) / แมงมุมผี / ราชาแมลง(บอส) — ขาเดิน ปีกกระพือได้จริง
- **โหมดเล็งเป้า** 4 แบบ: หน้าสุด / หลังสุด / เลือดมาก / เลือดน้อย (หน้าสุด = ใกล้ทางออกที่สุดตามทางเดินจริง)
- **2 โหมดเกม**: 10 เวฟ และ **ไม่สิ้นสุด** · **3 ระดับความยาก** ง่าย / ปกติ / ยาก
- **ระบบหาทางจริง (flow-field BFS)** ศัตรูเดินอ้อมป้อม/สิ่งกีดขวาง ระบบกันวางป้อมปิดทางตาย
- **4 ธีมแมพ** ทุ่งหญ้า / ป่าสน / ทุ่งดอกไม้ / โอเอซิส · สิ่งกีดขวางสุ่มใหม่ทุกเกม
- **🛠️ เครื่องมือสร้างแมพ** ลากเมาส์วาดแมพเอง บันทึกได้หลายแมพ (แมพจากเวอร์ชัน 2D ใช้ต่อได้)
- **คุณภาพภาพ 3 ระดับ** ต่ำ / กลาง / สูง (ลดให้อัตโนมัติถ้าเครื่องทำงานหนัก)
- ปรับความเร็วเกม x1 / x2 / x3 (ผลเหมือนกันทุกความเร็ว) · เสียงสังเคราะห์ในตัว · บันทึกสถิติแยกตามโหมด
- **📚 สารานุกรม** ในเกม: วิธีเล่น การควบคุม ป้อม ศัตรู เวฟ ตัวคูณ กลไกเกม ธีมแมพ และตารางปรับเกม
  - โมเดล 3D ลากหมุนได้, กราฟ, เครื่องคำนวณเลือดศัตรู, สนามตัวอย่างการหาทางแบบกดเล่นได้, ค้นหา
  - ตัวเลขทุกตัวดึงจากโค้ดเกมโดยตรง และทุกหน้ามีลิงก์ตรง เช่น `/#codex/towers/laser`

## ▶️ วิธีรัน (ต้องมี [Node.js](https://nodejs.org) 20 ขึ้นไป)

```bash
npm install        # ติดตั้งครั้งแรกครั้งเดียว
npm run dev        # เปิดเกมโหมดพัฒนา → เปิดลิงก์ที่ขึ้นในเบราว์เซอร์
```

คำสั่งอื่น:

```bash
npm run build      # build เว็บลงโฟลเดอร์ dist/
npm run preview    # เปิดดูผล build
npm test           # unit test
npm run test:e2e   # ทดสอบเล่นจริงในเบราว์เซอร์ (ครั้งแรกอาจต้อง npx playwright install chromium)
```

## ☁️ Deploy (Cloudflare)

โปรเจกต์มี `wrangler.jsonc` ตั้งค่าไว้แล้ว (เว็บ static จากโฟลเดอร์ `dist/`) — ตั้งค่าใน Cloudflare dashboard ครั้งเดียว:

1. เข้า **Workers & Pages** → เลือกโปรเจกต์ `demon-swarm-tower-defense`
2. **Settings → Build** → **Build command** ใส่ `npm ci && npm run build`
3. Deploy command ใช้ค่าเดิม (`npx wrangler deploy`) — ไม่ต้องตั้ง environment variables
